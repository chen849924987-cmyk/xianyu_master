## 1. 系统架构概览

### 1.1 逻辑架构

当前实现为 **Next.js 一体化**：管理面板与 API 同仓部署，浏览器自动化与任务脚本在 Node 侧执行。

```
┌─────────────────────────────────────────────────────────────┐
│                    浏览器（用户 / Playwright）               │
└───────────────────────────┬─────────────────────────────────┘
                            │ HTTP / SSE
┌───────────────────────────▼─────────────────────────────────┐
│  Next.js App Router                                          │
│  ├── app/page.tsx          控制台 UI（Tab：任务/定时/日志/登录） │
│  └── app/api/**/route.ts   REST + SSE                        │
├───────────────────────────┬─────────────────────────────────┤
│  lib/api-server.ts         任务执行、调度、日志、会话桥接      │
│  backend/tasks/*           具体自动化任务脚本（Playwright）    │
│  backend/store/*           定时任务等 JSON 持久化             │
└───────────────────────────┴─────────────────────────────────┘
```

### 1.2 与脚手架模板的差异说明

本仓库**非**典型「前后端分离 + RBAC + 关系型数据库」形态：无多租户账号体系，数据以本地 JSON / Excel / 登录态文件为主。以下章节按**实际代码**描述。

## 4. API 与前端视图（与实现对齐）

### 4.1 管理端视图

| 路径 | 说明 |
|------|------|
| `/` | 控制台；任务卡片链至功能工作台 |
| `/features/[slug]` | 单功能工作台（历史 / 实时 / 报错日志三区，当前占位） |
| `/#schedule` | 定时任务（Hash） |
| `/#logs` | 全局运行日志（Hash） |
| `/#session` | 登录态管理（Hash） |

注册表：`lib/feature-registry.ts`（`slug` ↔ `backend/tasks/*.js`）。

### 4.1.1 计划中的 Job / Feature API（v2.2，参考抖店）

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/jobs/run` | 启动任务子进程，返回 `{ jobId }` |
| GET | `/api/jobs/:jobId/logs` | **按 Job 的 SSE**（`log` / `end` 事件，支持 chunks 重放） |
| POST | `/api/jobs/:jobId/report-error` | 中止任务并落盘 trace / video / 页面快照 |
| GET | `/api/features/[slug]/history` | 该功能历史执行记录 |
| GET | `/api/features/[slug]/runs/:id` | 单次运行详情（含日志与 `__JOB_STEP__` 解析） |

结构化进度：任务脚本输出 `[xianyu] __JOB_STEP__` + 单行 JSON（字段见 [开发路线](开发路线.md) §3.2）。

### 4.2 HTTP API 清单

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/tasks` | 获取可运行任务列表 |
| POST | `/api/tasks/run` | 立即运行指定任务 |
| GET | `/api/scheduled-tasks` | 列出定时任务 |
| POST | `/api/scheduled-tasks` | 新增定时任务 |
| PUT | `/api/scheduled-tasks/:id` | 更新定时任务 |
| DELETE | `/api/scheduled-tasks/:id` | 删除定时任务 |
| GET | `/api/logs` | 读取运行日志 |
| DELETE | `/api/logs` | 清空日志 |
| GET | `/api/events` | SSE 事件流 |
| GET / POST / DELETE | `/api/session` | 登录态查询、保存/校验、清除 |

### 4.3 SSE 约定

客户端使用 `EventSource` 连接 `GET /api/events`；事件负载为 JSON 文本，用于任务输出与状态更新（具体字段以 `lib/api-server.ts` 与路由实现为准）。

## 5. 数据与配置

| 类型 | 存储位置 | 说明 |
|------|----------|------|
| 登录态 | `.data/storage-state.json`（默认） | 勿提交 Git |
| 定时任务 | `backend/store/scheduled_tasks.json` | 本地 JSON |
| 运行日志 | `backend/store/task_logs.json` | 可通过 API 清空 |
| Job 产物（v2.2） | `.data/ui-job-artifacts/<jobId>/` | Report error：trace.zip、video、快照 |
| Feature 运行历史（v2.2） | `.data/feature-job-history.json` | per-feature 历史 API |
| 环境变量 | `.env` | `PORT`、`PLAYWRIGHT_HEADED`、`STORAGE_STATE_PATH` 等 |

## 6. 安全与合规要点

- 所有自动化在**本地**执行；遵守闲鱼平台使用条款，控制频率（参见 [功能规格说明.md](功能规格说明.md) 第 8 节）。
- 登录态与业务输出目录应位于 `.gitignore` 中。
