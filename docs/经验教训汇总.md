## 1. Next.js 与 API

### 1.1 文档与实现路径漂移

**问题描述**：功能规格或 PRD 仍写 `/api/schedules`、`/api/sse` 等旧路径，与 `app/api` 下实际路由不一致。

**根因分析**：架构从规划稿落地时路由命名调整，未同步回文档。

**解决方案**：以 `docs/技术方案设计.md` 与 `app/api/**/route.ts` 为单一事实来源；变更 API 时同时改技术方案与 `docs/README.md` 速查表。

**预防措施**：功能发布前运行 `python .clinerules/hooks/pre-check-docs.py`。

## 2. Playwright 与登录态

### 2.1 CDP 连接失败

**问题描述**：连接本机 Chrome 失败导致任务无法启动。

**根因分析**：未以远程调试端口启动浏览器，或端口与配置不一致。

**解决方案**：使用仓库内 `start_chrome.bat` 或核对环境变量；在代码中保留 launch 回退路径。
