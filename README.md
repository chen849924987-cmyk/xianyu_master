# 闲鱼自动化助手 (xianyu-master)

> **文档体系版本**：v2.1.0

本地化闲鱼运营自动化工具（Next.js + Playwright）。**完整说明、快速开始、API 与文档索引见 [docs/README.md](docs/README.md)。**

### 常用命令

```bash
pnpm install
npx playwright install chromium
pnpm dev
```
