# 抖店自动化 — 任务总览

约定：子任务完成后，将 `[ ]` 改为 `[x]`，并在行末补上完成时间（本地时间，格式 `YYYY-MM-DD HH:mm`）。

**与 Cursor Hook 联动**：在 Agent 里发送收尾词（如 `完成`、`commit`、`好了` 等，见 `harness/hooks/prompt-session-end.mjs` 的 `SESSION_END_PHRASES`）时，若同一条消息里带有 **任务序号**（如 `1.1`、`2.3`），Hook 会先把 **表中尚不存在的序号** 自动插入对应章节表格（如 `1.5` 插入「一、」下；**五章及以上**尚无标题时会插入 `## 五、扩展任务` 等），再尝试把对应行改为 `[x]` 并写入**当前完成时间**。标题写在序号后同一消息内即可，例如：`完成 1.5 晓风导出 SKU`。禁用自动插入：`HARNESS_SKIP_TODOLIST_AUTO_ADD=1`。Harness 总览见 [`harness/README.md`](./harness/README.md)。

## 一、自动上架

| 状态 | 任务 | 完成时间 |
| --- | --- | --- |
| [ ] | 1.1 晓风上货：按规则筛选商品，并同步/推送至抖店**草稿箱**（流程、选择器、异常重试） | |
| [ ] | 1.2 抖店草稿箱：批量/单款编辑（**价格、主图/头图、标题、类目属性**等），直至符合上架标准 | |
| [ ] | 1.3 正式上架后：在后台配置**降价/促销**活动（券、限时、满减等，按你实际玩法定） | |
| [ ] | 1.4 结果落表：导出或写入表格（建议 CSV/Excel），字段含**商品基础信息 + 成本参考 + 售价 + 预估利润空间**等 | |

**表格字段建议（1.4 可据此实现）**：商品 ID/链接、标题、类目、成本价、售价、毛利率/毛利额、上架时间、活动类型、备注。

## 二、监控市场流量趋势

| 状态 | 任务 | 完成时间 |
| --- | --- | --- |
| [ ] | 2.1 抖店**电商罗盘**：抓取近期热点/趋势商品数据，**每次记录采集日期** | |
| [ ] | 2.2 **晓风上货**：抓取/导出最新商品流量趋势（与罗盘字段对齐，便于日后合并） | |
| [ ] | 2.3 **1688**：对照趋势品，记录**近期成本价**区间或报价（可含链接、起批量） | |
| [ ] | 2.4 数据汇总：按日或按周合并为一张「趋势 × 成本」表，供选品与定价 | |
